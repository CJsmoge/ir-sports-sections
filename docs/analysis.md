# Анализ предметной области
## Проект: «Спортивные секции: запись и расписание»

## 1. Описание ПрО
Организация предоставляет услуги спортивных секций (футбол, плавание, йога и др.).
Клиенты (спортсмены) записываются на занятия, тренеры проводят тренировки,
администратор ведёт расписание и учёт посещаемости.
Сейчас всё ведётся в бумажных журналах и Excel — медленно и с ошибками.

## 2. Границы ПрО
| Входит | Не входит |
|---|---|
| Секции, тренеры, расписание | Медицинские справки |
| Запись на занятие | Бухгалтерия |
| Абонементы и оплата | Кадры |
| Отзывы и уведомления | Закупка инвентаря |
| Посещаемость | Логистика |

## 4. Бизнес-процессы «AS IS»

### Процесс 1: Запись на занятие
- Участники: спортсмен, администратор
- Шаги: звонок → просмотр журнала → поиск места → запись
- Проблемы: долго, ошибки, двойные записи

### Процесс 2: Составление расписания
- Участники: администратор, тренеры
- Шаги: сбор пожеланий → Excel → рассылка
- Проблемы: конфликты залов, ручная правка

### Процесс 3: Учёт посещаемости
- Участники: тренер, администратор
- Шаги: бумажный журнал → Excel
- Проблемы: двойная работа, потеря данных

### Процесс 4: Обратная связь
- Участники: спортсмен
- Шаги: устная жалоба
- Проблемы: не систематизировано
