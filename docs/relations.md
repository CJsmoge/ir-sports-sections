# Связи между сущностями
## Проект: «Спортивные секции: запись и расписание»

| A | Кардинальность | B | Описание |
|---|---|---|---|
| Client | 1 — N | Booking | Клиент делает записи |
| Trainer | 1 — N | Lesson | Тренер ведёт занятия |
| Hall | 1 — N | Lesson | Зал, где проводится занятие |
| Section | 1 — N | Lesson | Секция, к которой относится занятие |
| Lesson | 1 — N | Booking | На занятие записываются спортсмены |
| Booking | 1 — 0..1 | Attendance | Запись может иметь отметку посещаемости |

## Промежуточные сущности (M:N)
**Booking** — разрешает M:N между Client и Lesson:
один спортсмен может быть на многих занятиях,
на одно занятие может быть много спортсменов.

## Проверка целостности
- Все 7 сущностей связаны.
- Нет «висящих» сущностей.
- Кардинальности указаны явно.
- M:N разрешены через ассоциативную сущность.
