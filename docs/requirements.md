# Требования
## Проект: «Спортивные секции: запись и расписание»

## Функциональные требования

| ID | Требование | Источник | Приоритет |
|---|---|---|---|
| FR-01 | Система должна регистрировать спортсмена по email | Заказчик | Must |
| FR-02 | Система должна аутентифицировать пользователя по email и паролю | Заказчик | Must |
| FR-03 | Система должна отображать расписание занятий на неделю вперёд | Спортсмен | Must |
| FR-04 | Система должна фильтровать расписание по секции, тренеру, залу, уровню | Спортсмен | Must |
| FR-05 | Система должна позволять спортсмену записаться на занятие при наличии свободных мест | Спортсмен | Must |
| FR-06 | Система должна позволять спортсмену отменить запись не позднее чем за 2 часа до занятия | Спортсмен | Should |
| FR-07 | Система должна отображать список своих записей спортсмену | Спортсмен | Must |
| FR-08 | Система должна позволять тренеру видеть список группы на занятие | Тренер | Must |
| FR-09 | Система должна позволять тренеру отмечать посещаемость за 1 клик | Тренер | Must |
| FR-10 | Система должна позволять администратору создавать, изменять и удалять занятия в расписании | Администратор | Must |
| FR-11 | Система должна автоматически проверять конфликты залов и тренеров при создании занятия | Администратор | Must |
| FR-12 | Система должна отправлять уведомление спортсмену о подтверждении/отмене записи | Спортсмен | Should |

## Проверка качества
- **Полнота:** все 3 роли покрыты.
- **Непротиворечивость:** конфликтов между FR не обнаружено.
- **Выполнимость:** FR-12 может быть отложен во вторую итерацию.
