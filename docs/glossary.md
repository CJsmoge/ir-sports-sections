# Глоссарий предметной области

| Термин | Определение |
|---|---|
| Секция | Направление занятий (футбол, плавание, йога) |
| Тренер | Специалист, ведущий занятия |
| Спортсмен | Клиент, записывающийся на занятие |
| Занятие | Единичное тренировочное событие в расписании |
| Расписание | Набор занятий с датой, временем и местом |
| Группа | Коллектив спортсменов одного уровня |
| Абонемент | Право на N посещений за период |
| Запись | Оформление спортсмена на занятие |
| Слот | Временной интервал занятия |
| Зал | Место проведения занятия |
| Уровень | Квалификация группы (новичок/средний/про) |
| Посещаемость | Факт присутствия спортсмена на занятии |
