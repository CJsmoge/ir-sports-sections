# Сущности и атрибуты
## Проект: «Спортивные секции: запись и расписание»

## Client (Спортсмен)
**Назначение:** описывает клиента, записывающегося на занятия.
**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT | Да | PK |
| name | VARCHAR(100) | Да | ФИО |
| phone | VARCHAR(20) | Да | Телефон (уникальный) |
| email | VARCHAR(255) | Нет | Email |
| created_at | TIMESTAMP | Да | Дата регистрации |

---

## Trainer (Тренер)
**Назначение:** специалист, ведущий занятия.
**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT | Да | PK |
| name | VARCHAR(100) | Да | ФИО |
| phone | VARCHAR(20) | Да | Телефон |
| specialization | VARCHAR(100) | Да | Специализация |
| is_active | BOOLEAN | Да | Активен ли тренер |

---

## Section (Секция)
**Назначение:** направление занятий (футбол, плавание и т.д.).
**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT | Да | PK |
| name | VARCHAR(100) | Да | Название секции |
| description | TEXT | Нет | Описание |
| level | VARCHAR(20) | Да | Уровень (новичок/средний/про) |

---

## Hall (Зал)
**Назначение:** место проведения занятий.
**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT | Да | PK |
| name | VARCHAR(50) | Да | Название зала |
| capacity | INT | Да | Вместимость |
| address | VARCHAR(255) | Нет | Адрес |

---

## Lesson (Занятие)
**Назначение:** единичное занятие в расписании.
**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT | Да | PK |
| trainer_id | INT | Да | FK → Trainer |
| hall_id | INT | Да | FK → Hall |
| section_id | INT | Да | FK → Section |
| start_at | TIMESTAMP | Да | Дата и время начала |
| duration_min | INT | Да | Длительность в минутах |
| capacity | INT | Да | Максимум мест |
| status | VARCHAR(20) | Да | planned/done/cancelled |

---

## Booking (Запись)
**Назначение:** запись спортсмена на занятие.
**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT | Да | PK |
| client_id | INT | Да | FK → Client |
| lesson_id | INT | Да | FK → Lesson |
| status | VARCHAR(20) | Да | confirmed/cancelled |
| created_at | TIMESTAMP | Да | Дата записи |

---

## Attendance (Посещаемость)
**Назначение:** отметка о посещении занятия.
**Первичный ключ:** id (INT)

| Атрибут | Тип | Обяз. | Описание |
|---|---|---|---|
| id | INT | Да | PK |
| booking_id | INT | Да | FK → Booking |
| visited | BOOLEAN | Да | Пришёл ли спортсмен |
| marked_at | TIMESTAMP | Да | Когда отмечено |
