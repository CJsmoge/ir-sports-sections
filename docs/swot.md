# SWOT-анализ
## Проект: «Спортивные секции: запись и расписание»

## Strengths (сильные стороны)
1. Простой интерфейс — запись за 3 шага.
2. Мобильная версия для тренера.
3. Единый экран расписания для администратора.
4. Автопроверка конфликтов залов.
5. Современный стек технологий.

## Weaknesses (слабые стороны)
1. Нет интеграции с онлайн-платежами в MVP.
2. Нет нативного мобильного приложения (только веб).
3. Ограниченное время — 4 недели.
4. Один разработчик.
5. Нет интеграции с медицинскими системами.

## Opportunities (возможности)
1. Рост популярности ЗОЖ и любительского спорта.
2. Партнёрство с фитнес-клубами и школами.
3. Интеграция с агрегаторами спортивных услуг.
4. Масштабирование на несколько городов.

## Threats (угрозы)
1. Конкуренция: МойСпорт, Sportzania, Fitmost.
2. Изменения 152-ФЗ (персональные данные).
3. Экономический спад — снижение спроса на платные секции.
4. Демпинг со стороны бюджетных секций.
