# ir-sports-sections

# Комплексный учебный проект: от проектирования до веб-приложения

Учебные проекты по дисциплинам УП.01, УП.03 и практикуму «Языковой портал».

**Автор:** [Нестерова Полина 2ВР-2-25]  
**Период:** 2026 год.

## Описание проекта

Проект прошел полный цикл разработки: от анализа предметной области и проектирования базы данных до создания клиентской части (вёрстки) и полноценного веб-приложения с сервером и базой данных.

В репозитории представлены материалы по трем направлениям:
1. **УП.01** — проектирование информационных ресурсов (анализ, требования, архитектура, БД).разработка веб-приложения на стороне клиента (HTML/CSS, адаптивность, Bootstrap, Tailwind).
2. **Практикум «Языковой портал»** — полноценное веб-приложение с сервером Node.js и БД PostgreSQL.

## Структура репозитория

- `docs/` — документация по УП.01 (анализ, требования, архитектура).
- `diagrams/` — ER- и UML-диаграммы.
- `sql/` — DDL-скрипты для PostgreSQL.
- `web-client/` — вёрстка по УП.03 (чистый CSS, Bootstrap, Tailwind).
- `web-school/` — сайт «Языковой портал» (HTML/CSS + JS).
- `server.js` — сервер на Node.js + Express (Задание 4).
- `database.sql` — SQL-скрипт для создания базы данных.
- `package.json` — зависимости проекта.

## 3. Практикум «Языковой портал» (LinguaPro)

**Тема:** Создание веб-приложения с сервером и базой данных.

### Описание
Многостраничный сайт языковой школы с серверной частью на Node.js и базой данных PostgreSQL. Позволяет:
- Просматривать информацию о школе и преимуществах.
- Изучать доступные курсы.
- Рассчитывать стоимость обучения.
- Оставлять заявки на бесплатный урок с валидацией.
- Сохранять заявки в БД.

### Структура
- `web-school/index.html` — главная страница.
- `web-school/courses.html` — курсы и калькулятор.
- `web-school/booking.html` — форма записи.
- `web-school/css/style.css` — стили.
- `web-school/js/main.js` — логика калькулятора, слайдера и валидации.
- `server.js` — сервер Express и API.
- `database.sql` — SQL-скрипт.

### Технологии
- **Frontend:** HTML5, CSS3, JavaScript (ES6), Fetch API.
- **Backend:** Node.js, Express.js.
- **БД:** PostgreSQL (драйвер `pg`).
- **Архитектура:** Клиент-серверная (REST API).
