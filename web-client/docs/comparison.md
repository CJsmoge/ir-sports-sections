# Сравнение Bootstrap и Tailwind

| Критерий | Bootstrap | Tailwind |
|---|---|---|
| Подход | Компонентный | Utility-first |
| Готовые компоненты | Да (navbar, cards) | Нет (собираем сами) |
| Размер CSS | ~200 КБ (весь) | ~10–30 КБ (только нужное) |
| Кастомизация | Ограничена | Максимальная |
| Скорость старта | Быстрая | Средняя |
| HTML | Чистый | Громоздкий |
| JS-плагины | Есть (modal, dropdown) | Нет (нужен свой) |
| Когда выбирать | MVP, типовой проект | Уникальный дизайн |
